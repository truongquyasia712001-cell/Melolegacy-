# Melolegacy - Music Composition & Learning App

**Project**: Free music composition, notation, and ear training app for iPad

**Tech Stack**: 
- Frontend: React 18 + TypeScript + PWA
- Music: Verovio 6.3.0 + MusicXML
- Recognition: ONNX Runtime + PyTorch.js
- Backend: Firebase Realtime + Firestore

**5 Core Priorities**:
1. View sheet music (Verovio rendering)
2. Real-time handwriting symbol recognition (ONNX)
3. OMR (Optical Music Recognition) from images
4. Collaboration (Firebase Realtime)
5. Ear training (Perfect Ear-style exercises)
